1. MISSION OBJECTIVE & OPERATIONAL ENVELOPE
--------------------------------------------------------------------------------
Heimdallv2 is an edge-optimized, real-time aerial reconnaissance and spatial
traffic telemetry engine engineered for persistent monitoring of multi-lane
intersections, arterial roadways, and complex urban choke points from drone-borne
cameras (altitude: 40m - 120m AGL).

Operational Criteria:
  • Resolution Support   : 4K UHD (3840x2160) @ 30 FPS down to 1080p FHD
  • Hardware Target      : CUDA-accelerated edge/workstation GPUs (RTX 5050 Laptop+)
  • Multi-Class Targets  : Cars, Light Goods (Vans), Heavy Goods (Trucks),
                           Buses, Motorcycles, Bicycles, Auto-Rickshaws, Pedestrians
  • Identity Stability   : Single persistent Track ID per entity from FOV entry
                           to boundary exit (>85% track persistence rate)
  • False Positive Rate  : 0% environmental clutter (Trees, Foliage, Pavements)

3. COMPUTER VISION & PERCEPTION SPECIFICATION
--------------------------------------------------------------------------------

3.1 Pure-GPU Batched Sliced Aided Hyper Inference (SAHI)
  • Problem: Direct downsampling of 4K footage (3840x2160) to 640x640 shrinks
    small road users (20px pedestrians and motorcycles) to sub-pixel noise.
  • Solution:
      1. Slices full 4K frame directly on GPU VRAM via PyTorch GPU interpolation.
      2. Assembles an optimal 3x2 tile grid with 20% spatial overlap.
      3. Concurrently executes all tiles in a single batch forward pass on CUDA.
      4. Reprojects tile-local boxes to global coordinate space and executes
         torchvision.ops.batched_nms in <1.5ms.

3.2 VisDrone Top-Down Aerial Weights Integration
  • Standard MS-COCO models suffer from a fundamental domain shift (horizontal
    ground photography vs. 90-degree nadir aerial perspective).
  • Heimdallv2 integrates VisDrone fine-tuned models (`yolov8s-visdrone.pt` and
    `yolov8x-visdrone.pt`), yielding high feature activation on top-down
    geometries:
      - Pedestrians / People      : 22+ detections per frame (vs. 0 on raw COCO)
      - Motorcycles / Scooters    : 47+ detections per frame
      - Auto-Rickshaws (Tricycles): Native multi-class identification

3.3 Cross-Class Containment & False-Positive Suppression
  • Windshield / Driver Suppression: If a pedestrian or bike is detected >60%
    within an enclosing vehicle bounding box, the nested detection is pruned.
  • Strict Environmental Whitelist: All non-traffic COCO classes (trees, plants,
    benches, boats, umbrellas) are discarded at the neural output stage.


4. TRACKING, KINEMATICS & TRAJECTORY SPECIFICATION
--------------------------------------------------------------------------------

4.1 Camera Motion Compensation (GMC)
  • Gimbal tilt and drone drift break standard Kalman filter assumptions.
  • BoT-SORT computes background optical flow via OpenCV Sparse Lucas-Kanade,
    generating an affine transformation matrix M:
      [x'] = M * [x]
      [y']       [y]
  • Kalman state distributions are transformed before distance matrix evaluation.

4.2 Calibrated Association Parameters
  • new_track_thresh   : 0.35  (Strict initialization: eliminates spurious noise)
  • track_high_thresh  : 0.20  (Stage 1 high-confidence association)
  • track_low_thresh   : 0.05  (Stage 2 low-confidence association: prevents lost tracks)
  • match_thresh       : 0.75  (Geometric distance cost threshold)
  • track_buffer       : 90    (Coasting lifespan: 3.0 seconds @ 30 FPS)
  • fuse_score         : False (Pure geometric / motion cost matching)

4.3 Trajectory Kinematics & Sub-Pixel Smoothing
  • EMA Centroid Smoothing:
      C_smooth(t) = alpha * C_raw(t) + (1 - alpha) * C_smooth(t - 1)   [alpha = 0.70]
  • Occlusion Interpolation: Connects tracks missing for <= 6 frames with
    linear interpolation to prevent trajectory breaks.
  • Quadratic Bézier Spline Trails: Renders trajectory trails using continuous
    midpoint Bézier curves on HTML5 Canvas.


5. DATA MODEL & SCHEMA (LEVEL 1 SPECIFICATION)
--------------------------------------------------------------------------------

5.1 Normalized Taxonomy Class Hierarchy
  • PERSON        : (#00FFB2) - Pedestrians, walking individuals, crowds
  • BICYCLE       : (#00E5FF) - Cyclists, non-motorized bicycles
  • MOTORCYCLE    : (#C8F23A) - Motorcycles, motor scooters, mopeds
  • CAR           : (#38BDF8) - Sedans, hatchbacks, SUVs, taxis
  • LGV           : (#FB923C) - Delivery vans, pickup trucks, utility vehicles
  • HGV           : (#F43F5E) - Heavy cargo trucks, semi-trailers, tippers
  • BUS           : (#A855F7) - Transit buses, intercity coaches, minibuses
  • OTHER_VEHICLE : (#E2E8F0) - Auto-rickshaws, tricycles, emergency vehicles

5.2 SQLite Relational Schema (`outputs/heimdall.db`)
  • Table `heimdall_sessions`:
      session_id TEXT PRIMARY KEY, filename TEXT, duration_seconds REAL,
      total_frames INT, total_tracks INT, status TEXT, created_at TIMESTAMP
  • Table `heimdall_tracks`:
      track_id INT PRIMARY KEY, session_id TEXT, raw_class TEXT,
      normalized_class TEXT, confidence REAL, first_seen REAL, last_seen REAL,
      first_frame INT, last_frame INT, total_frames INT, average_speed REAL,
      max_speed REAL, is_stationary BOOL, is_uncertain BOOL
  • Table `heimdall_trajectory_points`:
      point_id INT PRIMARY KEY AUTOINCREMENT, track_id INT, frame_index INT,
      timestamp REAL, x REAL, y REAL, speed REAL, heading REAL, bbox_json TEXT
